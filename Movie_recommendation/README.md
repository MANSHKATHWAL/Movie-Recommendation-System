# Movie Recommendation System 🎬

## Project Description
The Movie Recommendation System is a Python-based web application developed using Streamlit. It recommends movies based on the user's selected movie using content-based filtering.

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity

## Features
- Interactive movie dashboard
- Movie selection by genre
- Movie details including year and rating
- Personalized movie recommendations
- Display of all available movies

## How to Run the Project

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   streamlit run app.py
   ```

## Recommendation Technique
This project uses TF-IDF Vectorization and Cosine Similarity to identify movies with similar genres and descriptions.
